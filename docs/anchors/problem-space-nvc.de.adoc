= Problem Space NVC
:categories: requirements-engineering, communication-presentation
:roles: business-analyst, product-owner, consultant, ux-designer, team-lead
:proponents: Marshall Rosenberg
:tier: 3
:definition: Nonviolent Communication (NVC, Gewaltfreie Kommunikation) ist Marshall Rosenbergs Kommunikationsmethode: Sie trennt konkrete Beobachtungen von Bewertungen und drückt Gefühle aus, die universellen menschlichen Bedürfnisse dahinter sowie spezifische Bitten statt Forderungen. Im Problem Space angewandt, deckt sie die echten Bedürfnisse hinter Beschwerden und Feature-Wünschen auf. Das stützt die Requirements-Ermittlung und die Konfliktlösung im Team.
:tags: nvc, communication, empathy, conflict-resolution, requirements
:related: jobs-to-be-done, impact-mapping, user-story-mapping

[%collapsible]
====
Vollständiger Name:: Problem Space in Nonviolent Communication

[discrete]
== *Kernkonzepte*:

Beobachtungen:: Konkrete, objektive Fakten ohne Bewertung

Gefühle:: Emotionen, die aus Beobachtungen entstehen

Bedürfnisse:: Universelle menschliche Bedürfnisse, die Gefühlen zugrunde liegen

Bitten:: Spezifische, umsetzbare Bitten (keine Forderungen)

Empathische Verbindung:: Verstehen vor Problemlösung

Trennung von Beobachtung und Interpretation:: Vermeidung von Urteilen

Bedürfnisbasierte Konfliktlösung:: Lösungen finden, die die Bedürfnisse aller erfüllen


Schlüsselvertreter:: Marshall Rosenberg

[discrete]
== *Anwendung in der Softwareentwicklung*:

* Requirements-Ermittlung, die echte Nutzerbedürfnisse aufdeckt
* Stakeholder-Kommunikation und Konfliktlösung
* User-Story-Formulierung mit Fokus auf Bedürfnisse
* Retrospektiven und Teamkommunikation
====
