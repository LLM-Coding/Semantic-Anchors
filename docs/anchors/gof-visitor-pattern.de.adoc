= GoF-Visitor Pattern
:categories: design-principles
:roles: software-developer, software-architect
:umbrella: gof-design-patterns
:tier: 3
:definition: Das Visitor Pattern ist ein Behavioral-Entwurfsmuster der GoF von Erich Gamma, Richard Helm, Ralph Johnson und John Vlissides. Es repräsentiert eine Operation, die auf den Elementen einer Objektstruktur ausgeführt wird. Damit lässt sich eine neue Operation definieren, ohne die Klassen der Elemente zu ändern, auf denen sie operiert. Die Operation liegt in einem eigenen Visitor-Objekt und wird per Double Dispatch ausgewählt.
:proponents: Erich Gamma, Richard Helm, Ralph Johnson, John Vlissides
:tags: GoF, design pattern, behavioral, visitor, double dispatch, operations, traversal
:related: gof-design-patterns, gof-iterator-pattern, gof-interpreter-pattern

Vollständiger Name:: GoF Visitor Pattern (Behavioral)

[discrete]
== *Absicht*:
Repräsentiere eine Operation, die auf den Elementen einer Objektstruktur ausgeführt werden soll. Visitor ermöglicht es, eine neue Operation zu definieren, ohne die Klassen der Elemente zu ändern, auf denen sie operiert.
