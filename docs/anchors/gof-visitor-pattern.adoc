= GoF-Visitor Pattern
:categories: design-principles
:roles: software-developer, software-architect
:umbrella: gof-design-patterns
:tier: 3
:definition: The Visitor pattern is a behavioral GoF design pattern by Erich Gamma, Richard Helm, Ralph Johnson and John Vlissides that represents an operation to be performed on the elements of an object structure. It lets you define a new operation without changing the classes of the elements on which it operates, because the operation lives in a separate visitor object and is selected through double dispatch.
:proponents: Erich Gamma, Richard Helm, Ralph Johnson, John Vlissides
