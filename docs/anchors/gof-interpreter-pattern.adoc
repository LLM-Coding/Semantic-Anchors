= GoF-Interpreter Pattern
:categories: design-principles
:roles: software-developer, software-architect
:umbrella: gof-design-patterns
:tier: 3
:definition: The Interpreter pattern is a behavioral GoF design pattern by Erich Gamma, Richard Helm, Ralph Johnson and John Vlissides that, for a given language, defines a representation of its grammar together with an interpreter that uses this representation to interpret sentences in the language. It suits small grammars and domain-specific languages, where each grammar rule becomes part of the representation the interpreter evaluates.
:proponents: Erich Gamma, Richard Helm, Ralph Johnson, John Vlissides
:tags: GoF, design pattern, behavioral, interpreter, grammar, DSL, parsing

Full Name:: GoF Interpreter Pattern (Behavioral)

[discrete]
== *Intent*:
